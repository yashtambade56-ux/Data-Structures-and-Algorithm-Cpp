PROGRAMMING ASSIGNMENT 1 - TWO POINTER TECHNIQUE

This folder contains three simple code files:
1. assignment.cpp - C++
2. Assignment.java - Java
3. assignment.py - Python

Each file contains all four required methods:
1. Remove Duplicates - Brute Force
2. Remove Duplicates - Two Pointers
3. Pair Sum - Brute Force
4. Pair Sum - Two Pointers

Sample input values are written inside the programs to keep them easy to run.

Run C++:
g++ -std=c++17 assignment.cpp -o assignment
./assignment

Run Java:
javac Assignment.java
java Assignment

Run Python:
python assignment.py

Note:
The input arrays must be sorted. For duplicate removal with two pointers,
only the first k elements are the final unique array.
Pair Sum prints zero-based indices.
